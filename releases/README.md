# AnthroStat — Releases

Prebuilt Windows installers for **AnthroStat v0.1.0**. No build tools required — just download and run.

| File | Type | Recommended |
|------|------|-------------|
| **`AnthroStat_0.1.0_x64-setup.exe`** | NSIS installer (`.exe`) | ✅ Yes |
| `AnthroStat_0.1.0_x64_en-US.msi` | MSI installer | For managed/enterprise installs |

## Install

1. Download **`AnthroStat_0.1.0_x64-setup.exe`**.
2. Run it. If Windows SmartScreen warns (the build is unsigned), click **More info → Run anyway**.
3. Launch AnthroStat, open ⚙️ Settings, and paste or ✨ auto-detect your Claude `sessionKey`.
